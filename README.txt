CAFÉ MOBILE - PROJETO BASEADO NO INDEX.HTML ENVIADO

Estrutura:
- index.html
- css/style.css
- js/app.js
- manifest.json
- sw.js
- icons/icon-192.png e icon-512.png

Como executar:
1. Abra a pasta no VS Code.
2. Use Live Server ou execute: python -m http.server 8000
3. Abra http://localhost:8000
4. Câmera e Service Worker precisam de HTTPS ou localhost.
5. Para testar no celular, publique em hospedagem HTTPS e abra o endereço no aparelho.

O projeto mantém o cardápio e os nomes de classes do HTML enviado e acrescenta câmera, galeria, contador, legenda e recursos PWA.
